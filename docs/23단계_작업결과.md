## 1. 왜 바꿨나

| 문제 | 원인 |
|---|---|
| "캘리브레이션"을 누르면 바로 "캘리브레이션 중 (4/4 완료)"가 되고 클릭이 무시됨 | 버튼을 누르면 녹색 매트 자동 검출이 먼저 돈다. 이 매트는 왼쪽이 계단 모양이고 오른쪽에 퍼팅 그린이 붙어 있어서, 자동 검출이 **틀린 4점으로 "성공"**했다. 4점이 이미 차 있으니 클릭이 모두 무시됐다. |
| 다시 눌러도 같은 결과 | 자동 검출이 매번 같은 틀린 답을 낸다. 사용자가 직접 지정할 방법이 없었다. |
| 매트 크기 `세로 10000` 오타 | 입력 범위가 1~100000이라 오타를 막지 못했다. |
| 화면에 "앱: 포트 9000 사용 불가"가 계속 보임 | 아래 4절 참고 (실제로는 화면 표시 버그) |

실제로 잴 영역은 매트 위의 **가로 3000mm x 세로 1000mm**다 (화면에서 긴 쪽이 가로). 앞으로 다른 규격(4500x2000 등) 매트에도 설치되고 매트 모양도 제각각이라, **기본은 수동 지정**으로 바꿨다.

## 2. 구현 내용

### 2-1. 캘리브레이션 흐름 (`src/engine.py`, `src/ui/main_window.py`)

새 설정은 `calibration.auto_detect`이고 기본값은 **false**다.

| auto_detect | "캘리브레이션" 버튼을 누르면 |
|---|---|
| false (기본) | 모서리를 모두 지우고 바로 **수동 4점 클릭 모드** (자동 검출 안 함) |
| true | 자동 검출 결과를 저장하지 않고 하늘색 선으로 **제안**만 보여준다. "이 모서리로 확정" 또는 "직접 지정"을 고른다. 제안이 떠 있을 때 바로 클릭해도 직접 지정으로 본다. 검출에 실패하면 수동 모드. |

화면 조작:

| 조작 | 동작 |
|---|---|
| 왼쪽 클릭 | 모서리 점 찍기 (좌상 → 우상 → 우하 → 좌하) |
| **오른쪽 클릭** | 마지막 점 취소 |
| "다시 지정" 버튼 | 찍은 점 모두 지우기 (캘리브레이션 버튼 재클릭과 같음) |
| 4점 완료 후 점 근처를 **드래그** | 그 점을 옮김. 놓으면 행렬을 다시 계산해 저장한다 (미세 조정). |
| 마우스 이동 | **돋보기**: 마우스 주변을 화면 기준 3배로 확대하고 빨간 십자선을 보여준다 (180x180px 창) |

- 안내 띠(골드): "좌상 → 우상 → 우하 → 좌하 순서로 실제 측정 영역(3000x1000mm)의 모서리를 클릭하세요 (n/4) · 오른쪽 클릭: 마지막 점 취소"
- 4점 검사: 4번째 점을 찍으면 `check_corners()`로 검사한다 (볼록한 사각형인지, 순서가 맞는지, 화면 안인지).
  - 문제가 없으면 저장한다.
  - 문제가 있으면 저장하지 않고 4점을 지운 뒤 이유를 보여준다. 예: "저장하지 않음: 점 순서(좌상 → 우상 → 우하 → 좌하)나 사각형 모양이 올바르지 않습니다. 다시 찍어 주세요."
  - 드래그로 옮긴 결과도 같은 검사를 거친다. 이상하면 옮기지 않는다.
- 엔진에 새로 생긴 동작: `start_calibration()`(결과 `manual` / `proposed` / `auto_failed`), `accept_calibration_proposal()`, `reject_calibration_proposal()`, `undo_last_corner()`, `move_calibration_corner()`

## 4. 포트 9000 문제: 원인과 조치

- **원인**: 실제 포트 충돌이 아니라 **화면 표시 버그**였다.
  - 화면(MainWindow)은 엔진이 시작되기 **전에** 만들어진다. 이때 통신 상태 문구를 한 번 그리는데, 서버가 아직 안 열려서 "포트 9000 사용 불가"로 그려진다.
  - 그 뒤로는 앱이 접속하거나 통신 설정을 바꿀 때만 문구를 다시 그렸다. 그래서 잘못된 문구가 계속 남아 있었다.
  - 로그(`logs/engine.log`)에는 매번 "엔진 시작 - 통신 대기 중 (TCP 포트 9000)"으로 정상 기록돼 있었다.
- **조치**: 엔진이 시작되면 `changed` 시그널을 보내고, 화면이 이걸 받아 통신 문구를 다시 그리게 했다.
  - 오프스크린 확인: 시작 전 "앱: 포트 9123 사용 불가" → 시작 후 "앱: 대기 중 (포트 9123)"
- **netstat 확인** (실제 `main.py --ui` 실행):
  - 실행 중: `0.0.0.0:9000 LISTENING`
  - 테스트 접속 시 HELLO를 정상 수신: `{"cmd":"HELLO","version":"2.3",...,"frame_w":1440,"frame_h":810}`
  - 종료 후: 9000을 잡고 있는 프로세스 없음, 남은 python 프로세스 없음
  - 참고: LISTENING PID가 실행한 PID와 다른 것은 venv의 python.exe가 실제 파이썬을 자식 프로세스로 띄우기 때문이다 (정상).

### 6-2. 공 검출 (현재 장면, 프로필별)

| 대상 | 프로필 | 면적 | 원형도 | 결과 |
|---|---|---|---|---|
| 흰 공 (매트 왼쪽 끝) | 연습용 (흰 공) | 204px² (지름 18px) | 0.90 | 정상 검출 |
| 흰 컵 (홀) 3개 | 연습용 (흰 공) | 384~456px² | 0.81~0.83 | **공 조건(80~600, 원형도 0.7 이상)을 통과함** |
| 흰 티 (오른쪽 위, 매트 밖) | 연습용 (흰 공) | 144px² | 0.71 | 공 조건 통과 (매트 밖 필터로 걸러질 위치) |
| 매트 전체 | 연습용 (연두 공), 흰색 공 | 약 143,000px² | 0.13 | 녹색 매트 전체가 색 범위에 걸림 |

- **흰 컵**: 지금은 공이 컵보다 더 둥글어서 공이 뽑힌다. 하지만 **공이 화면에 없으면 컵이 공으로 잡힌다.** 흰 공으로 연습할 때는 `max_area`를 공에 맞게 더 좁히거나(예: 350), 컵 위치를 제외하는 처리가 필요하다.
- **연두 공 프로필**과 사용자가 만든 **"흰색 공" 프로필**은 HSV가 같다 (H 0~179, S 84 이상, V 108 이상). 색상(H)을 전부 허용하고 있어서 녹색 매트까지 걸린다.
  - "흰색 공" 프로필은 이름과 달리 흰 공을 찾지 못한다. 흰 공은 채도가 낮아서 "연습용 (흰 공)" 범위(H 0~180, S 0~60, V 180~255)를 써야 한다.
  - **정리함**: "흰색 공" 프로필은 연두 공과 HSV가 같아 의미가 없어서 `config/settings.json`에서 삭제했고, 활성 프로필을 **"연습용 (흰 공)"**(`practice`)으로 바꿨다.
  - 매트 위에 연두 공이 없어서 **연두 공 검출은 확인하지 못했다.**

### 6-3. 정확도 검증 — **현장 측정 대기**

> **현장 측정 대기**: 아래 표는 아직 빈칸이다. 측정 결과는 나중에 받아서 채우고 별도로 커밋한다.

## 7. 안 된 것 / 확인 못 한 것

- **정확도 검증 표** (6-3): 사람이 측정 영역 4점을 찍고 공을 옮겨야 한다.
- **공 위치별(가운데·오른쪽 끝) 면적**: 공이 왼쪽 끝에만 있었다.
- **연두 공 검출**: 매트 위에 연두 공이 없었다. 연두 공 프로필의 HSV는 매트까지 잡을 만큼 넓어서 다시 맞춰야 한다.
- **흰 컵 오검출**: 확인은 됐지만(공으로 잡힐 수 있음) 고치지는 않았다.
- **실제 창에서 조작**: 클릭·드래그·돋보기·오른쪽 클릭은 오프스크린 테스트로만 확인했다. 실제 화면에서 마우스로 써 보는 확인이 필요하다.
- ~~화면 흔들림~~ → **고침**: 안내 띠가 나타나고 사라질 때 카메라 화면 크기가 바뀌던 문제. 안내 띠 자리(높이 64px)를 항상 확보해 두도록 바꿨다 (숨겨도 자리는 남음). 크기가 바뀌면 클릭하려던 위치가 순간 움직여 모서리를 잘못 찍을 수 있었다.
- **작업목록.md 23단계 섹션과 커밋·push**: 정확도 결과를 받은 뒤 할 예정이다.

## 8. 다음에 할 일 (현장)

1. `run_ui.bat`을 실행한다. 상단이 "앱: 대기 중 (포트 9000)"인지 확인한다.
2. 설정 메뉴의 "프로필/매트 설정..."에서:
   - 프로필이 **"연습용 (흰 공)"**인지 확인한다 (이미 바꿔 둠).
   - 매트 크기가 3000x1000인지 확인한다.
   - "렌즈 왜곡 보정" k1이 -0.50인지 확인한다.
   - "검출 디버그 표시"를 켠다.
3. "캘리브레이션"을 누르고 측정 영역 네 모서리를 **좌상 → 우상 → 우하 → 좌하** 순서로 클릭한다. 줄자로 잰 테이프 표시가 있으면 그 위치를 찍는다.
   - 돋보기로 정확히 맞춘다.
   - 잘못 찍으면 오른쪽 클릭으로 취소하거나 드래그로 옮긴다.
4. 공을 6-3 표의 위치에 하나씩 놓는다. 줄자 값, 상단 "좌표" 배지(mm), 공 옆 숫자 A(면적)를 기록한다.
5. 연두 공이 있으면 매트 위에 놓고 흰 글씨(통과)인지 주황 글씨(걸러짐)인지 확인한다.
