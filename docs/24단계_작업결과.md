## 1. 왜 바꿨나

| 문제 | 내용 |
|---|---|
| 흰 공 색을 맞추기 어려움 | 사용자가 만든 "흰색 공" 프로필(S 106~117, V 37~216)로는 흰 공이 잡히지 않고 매트 잔털만 점으로 걸렸다. 흰 공은 채도가 낮고 밝아서 슬라이더로 맞추기 어렵다. 현장마다 조명·공 색이 달라 쉬운 방법이 필요하다. |
| 흰 컵을 공으로 잡음 | 흰 컵(홀) 3개가 공 조건(면적·원형도)을 통과한다. 공이 화면에 없으면 컵을 공으로 잡는다 (23단계 보고). |
| 화면 전체 검색 | 매 프레임 화면 전체를 찾아서 잡음에 약하고 느리다. |

이번 단계 목표:
1. 화면에서 **공을 클릭하면** 그 주변 공 픽셀로 HSV 범위를 자동으로 만든다.
2. 공을 화면 전체가 아니라 **공이 있을 만한 위치 주변(검색 영역, ROI)**에서만 찾는다.

(고정된 흰 물체(컵) 제외, 공 크기·이동 기준의 mm 전환은 25단계에서 한다.)

## 2. 구현 내용

### 2-1. 클릭으로 공 색 자동 추출 (`src/detector.py` 계산, `src/ui/tuning_dialog.py`·`main_window.py` 화면)

사용법: 설정 > 검출 설정... (HSV 튜닝) 창에서

| 버튼 | 동작 |
|---|---|
| **화면에서 공 클릭해 색 잡기** | 메인 카메라 화면이 '색 추출 모드'가 된다. 안내 띠 "색 추출: 공의 가운데를 클릭하세요"가 뜨고 돋보기(23단계)도 나온다. 오른쪽 클릭이면 취소. |
| **추가 샘플** | 공을 다른 위치에 옮긴 뒤 다시 클릭하면 이전 샘플과 합쳐 범위를 다시 만든다 (위치별 조명 차이 대응). |
| **저장** | 콤보에 보이는 프로필에 덮어쓰기 |
| **새 프로필로 저장** | 새 이름을 물어보고 새 프로필로 저장 (지금 프로필은 그대로) |
| 체크박스 "면적 제안값도 함께 저장" | 공 면적의 0.4배 ~ 2.5배를 min_area / max_area로 저장 (기본 체크) |

계산 순서 (처리 프레임 좌표 기준):
1. **공 모양 얻기** (`sample_ball_pixels`)
   - 클릭 지점 반경 30px 안에서 클릭 지점과 색·밝기가 비슷한 픽셀만 고른다.
   - 그중 **클릭 지점과 이어진 덩어리** 하나만 공으로 본다 (단순 원으로 자르면 매트 픽셀이 섞임).
   - 검출과 같은 블러(9x9)를 거친 HSV 값을 쓴다. 그래야 실제 검출 결과와 맞는다.
2. **범위 만들기** (`color_range_from_pixels`)
   - 공 픽셀 H·S·V의 2%~98% 백분위수에 여유값(H 8, S 40, V 40)을 더한다.
   - 채도 중앙값이 40 미만(흰 공)이면 Hue는 의미가 없으므로 0~179 전체를 허용한다.
   - Hue가 빨강 경계(0/179)를 넘으면 H최소 > H최대로 돌려준다 (예: 172 ~ 6).
3. **시험 적용** (`evaluate_color_range`): 프레임 전체에 적용해서 다음을 잰다.
   - 클릭 위치의 공 덩어리 면적·지름·원형도
   - **공처럼 보이는 다른 덩어리 수**: 제안 면적 범위 안이고 원형도 0.7 이상인 것만 센다. 매트 4점이 있으면 매트 안만 센다.
4. **여유 줄여 보기** (`auto_color_range`)
   - 다른 덩어리가 있으면 여유 배율을 1.0 → 0.75 → 0.5 → 0.25 → 0으로 줄여 가며 다시 시험한다.
   - 다른 덩어리가 가장 적은 범위를 고른다. 같으면 여유가 큰 쪽을 고른다 (조명 변화에 강함).
   - 줄이다가 공 모양이 깎이면 멈춘다: 원형도 0.75 미만, 또는 면적이 기본 여유 때의 60% 미만.
     - 이 기준은 실제 화면 시험에서 추가했다. 처음에는 여유를 0까지 줄여 공 원형도가 0.70(경계)까지 떨어졌다.
5. 결과를 슬라이더에 채우고 마스크 미리보기로 보여준다. 결과 설명(범위, 공 면적·지름·원형도, 다른 덩어리 수, 면적 제안)도 표시하고 로그에 남긴다. **저장은 사용자가 눌러야 된다.**

**Hue 두 구간 지원** (`hsv_in_range`)
- `hsv_lower`의 H > `hsv_upper`의 H이면 [H최소~179] + [0~H최대]를 함께 본다.
- 예전 설정(H최소 ≤ H최대)은 그대로 동작한다.
- 튜닝 창 슬라이더도 그대로 쓴다. Hue 최소를 최대보다 크게 하면 된다.

### 2-2. 검색 영역 제한 (ROI) (`src/search.py` 신규, `src/detector.py`, `src/engine.py`)

검출기:
- `detect(frame, roi=None, prefer=None)` 형태로 바꿨다.
- roi `(x, y, w, h)` 안만 잘라서 블러·HSV·마스크를 만든다. 결과 좌표는 프레임 전체 기준이다.
- 폭·높이가 0인 roi는 "아무 데도 찾지 않음"이다.
- prefer(예상 위치)가 있으면 조건을 통과한 후보 중 **가장 가까운 것**을 고른다. 예전에는 가장 둥근 것을 골라서 흰 컵이 공보다 먼저 뽑힐 수 있었다.

상태별 검색 영역 (`SearchPlanner`):

| 상태 | 검색 영역 |
|---|---|
| IDLE / CALIBRATING / FINISHED | 전체 화면 (매트 밖 필터는 기존대로) |
| READY (시작점 없음) | 전체. 앱이 `SET_ADDR`로 어드레스를 정했으면 그 주변 `idle_radius_mm` |
| READY (시작점 있음) | 시작점 주변 `idle_radius_mm`(150mm). 공이 `lost_frames_full`(10)번 넘게 안 보이면 전체 (공을 옮겨 다시 등록할 수 있게) |
| ARMED | 시작점 주변만 (넓히지 않음: 다른 물체를 공으로 잡으면 퍼팅 시작으로 잘못 판단) |
| TRACKING | 예상 위치 = 직전 위치 + 속도 x 지난 시간. 반경 = `track_radius_mm`(120mm) + 속도 x 지난 시간 x 0.5 |
| TRACKING 중 놓침 | 놓친 프레임마다 반경 x1.5. `lost_frames_full`(10)번 넘게 놓치면 전체. 예상 위치가 화면 밖이면 아무 데도 찾지 않음 |

- mm 반경은 캘리브레이션으로 그 위치 근처의 픽셀 반경으로 바꾼다 (`Calibration.mm_radius_to_px`). 캘리브레이션이 없으면 픽셀 기본값(시작점 150px, 추적 120px)을 쓴다.
- 속도는 연속 검출로 계산한다 (지수 이동 평균. 간격이 0.3초를 넘으면 쓰지 않음).
- **넓힌 영역의 후보 검사** (`accept`): 공을 놓쳐 넓힌 상태에서 찾은 후보는 다음 조건일 때만 받아들인다. 맞지 않으면 버리고 개수를 센다.
  - 예상 위치에서 반경 안이어야 한다.
  - 공이 움직이고 있었다면(60px/s 이상), 직전 위치 → 후보 방향이 진행 방향과 약 60도 이내여야 한다.
  - 직전 위치 바로 근처(기본 반경의 25%)는 방향과 상관없이 받는다. 멈추는 중일 수 있기 때문이다.
- 정지·이탈 판정은 그대로다. 공이 사라지면 기존 `lost_duration`(2초) 뒤 "화면 이탈"로 끝난다 (테스트로 확인).
- 화면: "검출 디버그 표시"를 켜면 검색 영역을 얇은 사각형 + 원 + 십자로 그린다.
  - 평소는 주황, 놓쳐서 넓힌 상태는 빨강이다.
  - 왼쪽 위 글자: `ROI: full / start / addr / track / lost`
- 설정 `config/settings.json`의 `search` 항목 (값이 없으면 기본값):
  ```json
  "search": {"enabled": true, "idle_radius_mm": 150, "track_radius_mm": 120, "lost_frames_full": 10}
  ```
  `enabled: false`면 예전처럼 전체 검색한다 (비교·문제 해결용).

## 4. 측정 결과 (이 PC, 사람 조작 없이 한 것)

### 4-1. 검색 영역 켬/끔 처리 시간
- 조건: 엔진만 실행, 0.75배(1440x810), k1 -0.50, "연습용 (흰 공)" 프로필, 시작점 등록(READY) 상태, 각 20초
- 캘리브레이션이 무효 상태라 픽셀 기본 반경(150px)을 썼다. 캘리브레이션하면 150mm ≈ 65px라 영역이 더 작아진다.

| 검색 영역 | FPS | 처리 시간 평균 (최대) | 그중 공 검출 | 검색 영역 크기 |
|---|---|---|---|---|
| 끔 (화면 전체) | 52.2 | 11.6ms (57ms) | 8.1ms | 화면의 100% |
| **켬 (시작점 주변)** | **57.7** | **4.0ms** (42ms) | **0.33ms** | **화면의 1.2%** |

공 검출 시간이 약 25배 줄었다. 남은 시간은 대부분 전처리(약 2.9ms)다.

### 4-2. 색 추출 시험 (실제 화면 사진으로)
23단계에서 저장한 실제 처리 프레임(1440x810, k1 -0.50)으로 시험했다. 매트 왼쪽 끝 흰 공 (184, 392)을 클릭한 결과:

| 조건 | 추출 범위 (H / S / V) | 여유 | 공 면적 / 지름 / 원형도 | 공처럼 보이는 다른 덩어리 | 면적 제안 |
|---|---|---|---|---|---|
| 매트 4점 없음 | 0~179 / 0~66 / 175~255 | x0.75 | 207px² / 18.0px / 0.90 | 3개 (흰 컵 2, 매트 밖 흰 티 1) | 83 ~ 518 |
| 매트 4점 있음 (대략) | 0~179 / 0~46 / 195~255 | x0.25 | 186px² / 16.8px / 0.89 | 2개 (흰 컵) | 74 ~ 464 |

- **흰 공과 흰 컵은 색으로 구별되지 않는다.** 여유를 끝까지 줄여도 컵이 남는다.
- 대신 **검색 영역이 컵을 막는다.** 같은 사진에서 시작점 주변(반경 65px)만 찾으면 공만 잡히고, 공을 지운 사진에서는 아무것도 잡히지 않았다 (컵 무시).
- 화면 전체 검색 + 면적 제안 범위에서는 가운데 컵(1243, 405)이 공보다 먼저 뽑혔다. 검색 영역을 쓰거나 예상 위치에 가까운 후보를 고르는 방식이 필요한 이유다.

| 색 추출 (흰 공, 왼쪽 → 가운데·오른쪽 추가 샘플): 범위, 면적, 다른 덩어리 수, 저장한 프로필 값 | (현장 측정 대기) |
| 색 추출 (연두 공): 새 프로필, 녹색 매트와 구별되는지 | (현장 측정 대기) |
| 검색 영역이 공을 따라가는지 (디버그 표시) | (현장 측정 대기) |
| 컵에 들어가는 퍼팅: 컵을 공으로 잡는지, RESULT 궤적 | (현장 측정 대기) |
| 컵 옆을 지나는 퍼팅: 컵을 공으로 잡는지, RESULT 궤적 | (현장 측정 대기) |
| 23단계 정확도 검증 표 (공 다섯 곳: 줄자 vs 화면 mm) | (현장 측정 대기) |

## 5. 안 된 것 / 확인 못 한 것

- **4-3의 현장 측정 전부**: 사람이 공을 옮기거나 퍼팅해야 한다.
- **흰 컵**:
  - 시작점 주변 검색(READY·ARMED)에서는 막힌다.
  - 추적 중 공이 **컵에 들어가면** 문제가 남는다. 공이 사라진 바로 그 자리에 컵이 있어서, 넓힌 영역의 진행 방향 검사도 통과할 수 있다. 그러면 LOST 대신 컵 위치에서 "정지"로 끝날 수 있다.
  - 고정된 흰 물체를 빼는 처리는 25단계에서 한다.
- **연두 공 프로필**: 연두 공이 없어서 확인하지 못했다. 기존 "연습용 (연두 공)" 프로필은 매트까지 잡는 상태 그대로다. 색 잡기로 새로 만들어야 한다.
- **추적 반경**: 아주 빠른 퍼팅에서 공이 검색 영역을 벗어나는지는 실제 퍼팅으로 확인해야 한다. 벗어나면 다음 프레임부터 반경이 커지며 다시 찾는다.
- **화면 확인**: 색 추출 모드·검색 영역 그리기는 오프스크린으로만 확인했다.

## 6. 현장에서 할 일

1. `run_ui.bat` 실행 → 캘리브레이션(23단계 방법: 측정 영역 네 모서리 직접 클릭)
2. 설정 메뉴의 "검출 설정..."을 연다.
   - 흰 공을 매트 왼쪽에 놓고 **"화면에서 공 클릭해 색 잡기"** → 공 가운데를 클릭한다.
   - 공을 가운데·오른쪽으로 옮기며 **"추가 샘플"**을 한다.
   - **"새 프로필로 저장"** (예: "흰 공 (클릭)")
   - 연두 공이 있으면 같은 방법으로 새 프로필을 만든다.
3. 설정 메뉴의 "프로필/매트 설정..."에서 **"검출 디버그 표시"**를 켠다.
4. 시작 위치 등록 → 추적 준비 → 퍼팅을 한다. 컵에 들어가는 퍼팅과 컵 옆을 지나는 퍼팅을 각각 해 본다.
   - 확인할 것: 검색 영역(주황/빨강 사각형)이 공을 따라가는지, 컵을 공으로 잡는지, 결과 궤적
5. 23단계 정확도 표: 공을 다섯 곳에 놓고 줄자 값과 상단 "좌표" 배지(mm)를 기록한다.
