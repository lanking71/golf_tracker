# 좌표 정확도 측정 방법 (쉽게 설명)

> 23단계 "정확도 검증 표"를 채우기 위한 안내서입니다.
> 매트 전체에 눈금을 그릴 필요는 없습니다. **공을 놓은 자리를 줄자로 재기만** 하면 됩니다.

---

## 1. 왜 하나요?

볼 트래커는 카메라 화면의 **픽셀 위치**를 매트 위 **실제 거리(mm)**로 바꿔서 알려 줍니다.
화면 상단 **"좌표" 배지**에 `(1500, 500)mm`처럼 나오는 값입니다.

이 값이 **실제 위치와 얼마나 맞는지** 확인하려는 것입니다.

- 카메라가 광각 렌즈라 화면이 휘어 보이는데, 이 휨(왜곡)이 **절반 정도만** 펴진 상태입니다.
- 그래서 매트 **가운데**나 **양 끝**에서 몇 mm나 어긋나는지 직접 재 봐야 합니다.

---

## 2. 좌표는 어디가 기준인가요?

캘리브레이션 때 찍은 측정 영역(가로 3000mm x 세로 1000mm)의 **좌상단 모서리가 (0, 0)**입니다.

```
(0, 0) ─────────── x (긴 쪽: 0 → 3000mm) ───────────▶ (3000, 0)
   │
   │   y (짧은 쪽: 0 → 1000mm)
   ▼
(0, 1000) ──────────────────────────────────────────── (3000, 1000)
```

- **x** = 왼쪽 끝에서 오른쪽으로 얼마나 떨어졌나 (0 ~ 3000mm)
- **y** = 위쪽 끝에서 아래로 얼마나 떨어졌나 (0 ~ 1000mm)
- 방향은 **카메라 화면에서 보이는 방향** 기준입니다 (화면 왼쪽 위 = 좌상단).

---

## 3. 준비물

- 줄자 (3m 이상)
- 테이프 조각 4개 (마스킹 테이프 등)
- 골프공 1개 (지금 쓰는 흰 공)
- 기록할 종이 또는 휴대폰 메모

---

## 4. 순서

### 4-1. 측정 영역 네 모서리에 테이프 붙이기
1. 매트 위에 가로 3000mm x 세로 1000mm 직사각형을 줄자로 잽니다.
2. 네 모서리에 작은 테이프 조각을 붙입니다.
3. 직사각형이 반듯한지 확인합니다: **대각선 두 개의 길이가 같으면** 반듯합니다 (약 3162mm).

> 테이프는 캘리브레이션할 때 화면에서 "여기가 모서리"라고 정확히 찍기 위한 표시입니다.
> 실제 모서리와 화면에서 찍은 모서리가 **같은 점**이어야 좌표가 맞습니다.

### 4-2. 캘리브레이션
1. `run_ui.bat`을 실행합니다.
2. **"캘리브레이션"** 버튼을 누릅니다.
3. 화면에서 테이프 네 개를 **좌상 → 우상 → 우하 → 좌하** 순서로 클릭합니다.
   - 마우스를 가져가면 **돋보기**가 나오니 테이프 위치에 정확히 맞춰 클릭하세요.
   - 잘못 찍었으면 **오른쪽 클릭**으로 취소하고, 4점을 다 찍은 뒤에는 점을 **드래그**해서 옮길 수 있습니다.

### 4-3. 공 놓고 재기 (다섯 곳 반복)
1. 공을 매트 위 한 곳에 놓습니다 (아래 5절의 위치 참고).
2. **줄자로 공 중심 위치를 잽니다.**
   - **x**: 왼쪽 테이프 선(좌상단 테이프 ~ 좌하단 테이프를 잇는 선)에서 공 중심까지
   - **y**: 위쪽 테이프 선(좌상단 테이프 ~ 우상단 테이프를 잇는 선)에서 공 중심까지
   - 공 중심을 재기 어려우면 **공 옆면까지 재고 21mm(공 반지름)를 더하세요.**
3. 화면 상단 **"좌표" 배지**에 나온 값을 적습니다.
   - 숫자가 1~2mm씩 바뀌면 대략 가운데 값을 적으면 됩니다.

---

## 5. 공을 놓을 다섯 곳

정확히 그 자리에 놓을 필요는 없습니다. **대략 그 근처에 놓고, 놓은 자리를 정확히 재면** 됩니다.

```
   0                    1500                   3000  (x, mm)
 0 ┌─────────────────────────────────────────────┐
   │                     ④                       │  ← 위 가장자리 근처 (y ≈ 100)
   │                                             │
500│ ①                   ②                    ③ │  ← 가운데 줄 (y ≈ 500)
   │                                             │
   │                     ⑤                       │  ← 아래 가장자리 근처 (y ≈ 900)
1000└─────────────────────────────────────────────┘
(y, mm)
```

| 번호 | 위치 | 대략 어디에 (x, y mm) |
|---|---|---|
| ① | 왼쪽 끝 | (200, 500) |
| ② | **가운데** (가장 중요) | (1500, 500) |
| ③ | 오른쪽 끝 | (2800, 500) |
| ④ | 위 가장자리 근처 | (1500, 100) |
| ⑤ | 아래 가장자리 근처 | (1500, 900) |

## 7. 결과 보는 법 (예시)

| 줄자 | 화면 | 오차 |
|---|---|---|
| (1500, 500) | (1523, 488) | x로 23mm, y로 12mm 어긋남 (거리로 약 26mm) |

- 오차가 **어느 위치에서 큰지**를 봅니다. 가운데·양 끝 중 어디가 많이 틀리는지 알면 렌즈 왜곡 보정을 더 손볼지 판단할 수 있습니다.
- 참고: 골프공 지름이 약 43mm입니다. 오차가 공 반 개(약 20mm) 안쪽이면 꽤 잘 맞는 편입니다.

## 8. 자주 하는 실수

| 실수 | 결과 | 이렇게 하세요 |
|---|---|---|
| 캘리브레이션 때 테이프가 아닌 매트 가장자리를 찍음 | 모든 좌표가 같은 방향으로 밀림 | 꼭 테이프 위치를 찍기 |
| x, y를 바꿔서 잼 | 값이 엉뚱하게 나옴 | **x = 긴 쪽(0~3000), y = 짧은 쪽(0~1000)** |
| 공 옆면까지 재고 반지름을 안 더함 | 약 21mm 차이 | 옆면까지 쟀으면 +21mm |
| 위·아래 기준을 반대로 잼 | y가 1000에서 뺀 값처럼 나옴 | **화면에서 위쪽**이 y = 0 |
| 화면 배지에 "px"가 붙어 있음 | 캘리브레이션이 안 된 상태 | 4-2를 다시 하기 (배지는 "mm"로 나와야 함) |
